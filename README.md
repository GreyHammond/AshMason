# AshMason Website

A responsive static promotional site for the AshMason Minecraft server.

## Included
- Desktop and mobile responsive layout
- AshMason Adventurer's Guide artwork
- Java and Bedrock connection information
- Discord join buttons
- Bodyguards, quests, kits, economy, dDungeons Reborn, bounties, reputation, and progression sections
- No framework or build step required

## Run
Open `index.html` in a browser, or serve the folder with any static web server.

The Discord invite is the user-provided invite:
